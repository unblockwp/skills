# Changelog

## 0.1.0 (2026-10-30)

- First skills: `unblock-site-brief`, `unblock-design-system`, `unblock-build-page`,
  `unblock-content`, `unblock-dynamic-data`, `unblock-audit-accessibility`,
  `unblock-audit-performance`, `unblock-audit-seo`, `unblock-audit-code`.
- Planning kit templates, in `skills/unblock-site-brief/assets/`.
- Pre-launch checklist.
- Prompts library, 21 prompts in seven jobs.
- The content model: post types, taxonomies and field groups made through the site's field plugin,
  with the Unblock tools for ACF and Pods, Meta Box's own abilities, JetEngine's MCP server or the
  user; plugins the owner approved installed with `unblock/install-plugin`, ACF proposed on a site
  with none.
- SEO plugins: the brief lets the owner choose Yoast SEO, Rank Math, SEOPress, All in One SEO or none,
  with what each lets the agent do and the step the owner takes (Rank Math's setup wizard, SEOPress's
  abilities for social texts); the SEO title and meta description read and written with
  `unblock/get-seo` and `unblock/update-seo`, the same way with the four; the SEO audit reads them,
  never the plugins' analysis of an Unblock page.
- Design sessions: three stops for the user (the brief, the art direction picked on three directions
  rendered on a draft, the draft of the first page), the rest decided with the defaults and said;
  temporary photos chosen once for the site, kept by every direction; the page composed in one pass
  and reviewed in its code before writing, looked at once when a browser tool is connected, critiqued
  by a fresh subagent on request; the theme's global styles aligned on a new site.
