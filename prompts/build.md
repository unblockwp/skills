# Build pages

## Build a page from the sitemap

**Skill:** `unblock-build-page`. **You get:** the plan in a few lines, then the whole page composed as
a draft and checked, with its preview link and a report.

Weak:

```
Create a home page.
```

Strong:

```
Use the unblock-build-page skill.
Build the {page name} page from its entry in sitemap.md, on the site's design system.
Real copy from brief.md and voice.md; mark anything missing as [To confirm].
Show me the plan first. Build it as a draft, check it at phone and desktop width, and report.
```

## Build a landing page

**Skill:** `unblock-build-page`. **You get:** a single-purpose page with one action.

```
Use the unblock-build-page skill.
Build a landing page for {offer or campaign}, for {audience}, who arrive from {ad, email, social}.
The one action: {action}. The proof we can show: {reviews, figures, clients}.
No navigation away from the action except the footer. Show me the plan first, then build it as a
draft.
```

## Redo a section

**Skill:** `unblock-build-page`. **You get:** one section rebuilt, the rest of the page untouched.

```
Use the unblock-build-page skill.
On the {page name} page, redo the {section name} section: {what is wrong with it}.
It should {what it must do now}. Keep every other section as it is, and reuse the site's classes.
```

## Build from a Figma design

**Skill:** `unblock-from-figma`. **You get:** the design as responsive sections, its variables as
tokens, its images in the media library.

```
Use the unblock-from-figma skill.
Build {page or frame name} from this Figma file: {Figma link}.
Map the file's variables to the site's tokens and show me the values that match none.
Build it as a draft, compare it with the design at {frame width}, and tell me what you inferred for
mobile.
```
