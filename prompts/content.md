# Write the text

## Rewrite a page in the brand's voice

**Skill:** `unblock-content`. **You get:** the before and after of the headlines and buttons to
approve, then the new text, layout untouched.

Weak:

```
Make the text better.
```

Strong:

```
Use the unblock-content skill.
Rewrite the text of the {page name} page in our voice (voice.md), for {audience}.
What the page must make clear: {the key message}. Keep the layout and about the same length.
Show me the before and after of the headlines and buttons first.
```

## Fill the missing facts

**Skill:** `unblock-content`. **You get:** the `[To confirm]` markers replaced with your facts only.

```
Use the unblock-content skill.
Here are the facts the pages were missing:
{price list, opening hours, addresses, names, quotes with their author}.
Replace the [To confirm] markers with them. Leave any marker these facts do not cover, and list them.
```

## Write the alt texts and page titles

**Skill:** `unblock-content`. **You get:** an alt text for each image and a title and excerpt for each
page.

```
Use the unblock-content skill.
Go through every page of the site. Write an alt text for each image that carries meaning, and leave
decorative ones empty. Check each page's title and excerpt and propose better ones.
Show me the list before you apply it.
```
