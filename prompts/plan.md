# Plan the site

## Start a new site

**Skill:** `unblock-site-brief`. **You get:** the brief, the sitemap and the voice, with every guess
marked, and a summary to confirm. Nothing is built yet.

Weak:

```
Make me a website for my pottery studio.
```

Strong:

```
Use the unblock-site-brief skill.
I'm starting a site for {business}, {what it does} in {place}.
It's for {audience}, who come to {what they want to do}.
The one action that matters is {book / buy / call / visit}, and I'll count it by {how}.
Here is what I already have: {old site URL, brochure, notes}.
Sites I like: {URL} for {what you like}, {URL} for {what you like}.
Draft the kit, mark your guesses, and wait for my confirmation before building anything.
```

The strong version gives the subject, the audience and the goal, which every later step depends on,
and stops the AI before it builds on guesses.

## Redesign an existing site

**Skill:** `unblock-site-brief`. **You get:** a kit built from the pages the site already has, with
what to keep, redo or remove.

```
Use the unblock-site-brief skill.
This site needs a redesign. Read its current pages first.
What works today: {what to keep}. What does not: {what is wrong}.
The goal of the new version: {goal, with a number}.
Propose the sitemap with keep, redo or remove for each existing page, and wait for my confirmation.
```

## Plan one new page

**Skill:** `unblock-site-brief`. **You get:** the page's entry added to the sitemap.

```
Use the unblock-site-brief skill.
Add a page to the sitemap: {page name}, for {audience}, who arrive with the question {question}.
Its one action: {action}. What it must include: {content}.
Update sitemap.md and show me the entry before anything is built.
```
