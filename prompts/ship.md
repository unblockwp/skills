# Launch

## Check the site before launch

**Checklist:** [`checklists/pre-launch.md`](../checklists/pre-launch.md). **You get:** each item
checked or handed to you.

Weak:

```
Is the site ready?
```

Strong:

```
Go through checklists/pre-launch.md on the live site, logged out.
Check the [code] and [browser] items yourself and give me the result of each one.
List the [human] items for me to do. Change nothing.
```

## Fix the findings of an audit

**Skills:** `unblock-build-page`, `unblock-content`, `unblock-design-system`. **You get:** the
findings fixed one by one, each checked again.

```
Fix the findings of this report, the most severe first: {paste the report or name its findings}.
Use unblock-design-system for tokens, unblock-content for text and unblock-build-page for blocks.
Leave the findings that belong to the theme or other plugins, and tell me who can fix them.
Check each fix again and update the report.
```
