# Set the look

## Create the design system

**Skill:** `unblock-design-system`. **You get:** three directions to choose from, then the tokens,
fonts and base styles, with their contrast checked.

Weak:

```
Make it look modern and clean.
```

Strong:

```
Use the unblock-design-system skill, from brief.md.
Propose three directions that differ in ground, type and density, each tied to facts about
{the subject}. No code until I pick one.
Fixed points: {logo, brand colors, fonts}, or none.
I'd like it to feel {two or three precise words}, and not like {what you want to avoid}.
```

"Modern and clean" sends every site to the same look. Facts about the subject and a choice between
directions give a look of its own.

## Match an existing brand

**Skill:** `unblock-design-system`. **You get:** tokens built around the brand, with the colors that
fail contrast pointed out.

```
Use the unblock-design-system skill.
Build the design system from our brand: {brand colors with their codes}, {fonts}, {logo URL}.
Keep the brand colors as they are. Where one fails contrast for text, tell me and propose a shade
that passes for that use only.
Create the specimen page as a draft so I can look at it.
```

## Change the look of the site

**Skill:** `unblock-design-system`. **You get:** new token values, with the same names, so every page
follows.

```
Use the unblock-design-system skill.
Change the look of the whole site: {what to change: palette, fonts, radius, density}.
Keep the token names, change their values. Tell me which pages will change before you write.
```
